## 2. מימוש — עריכת היסטוריה גזרתית

**מטרה:** לאפשר עריכה של **היסטוריה גזרתית** (מצב תחקור מרחב / שכבת תחקירים — לא מידע עכשווי).

| משימה | סטטוס | הערות |
|--------|--------|--------|
| אפיון: מה ניתן לערוך (טווח זמן, ישויות, שכבות, קשר לציר זמן) | ⬜ | מול מוצר/מדור תחקור |
| הפרדה היסטורי ↔ עכשווי — כללים ב-UI | 🟡 חלקי | `spaceActive` נועל סדרן מרשמים; פאנל שכבות תחקיר — toggle בלבד |
| מסכי עריכה / טפסים (Figma → קוד) | 🟡 חלקי | `TahkirCreatePanel` — mock; אין עורך היסטוריה גזרתית |
| חיבור לנתונים (API / mock) | ⬜ | `src/data/tahkir/` להרחבה |
| שמירה / ביטול / הרשאות לפי תפקיד | ⬜ | קשור ל-§4 (דרג) ול-`editPermissions` |
| בדיקות זרימה: פתיחה מתחקור מרחב + שכבת תחקירים | ⬜ | [TAHKIR.md](./docs/TAHKIR.md) |

**קוד קיים לעגינה:** `TahkirUiContext`, `TahkirTimelineBar`, `TahkirCreatePanel`, `toggleSpace` / `tahkirLayerOpen`.

## 3. סידור קומפוננטות לפי מאמץ (כולל סיידבר משני)

**מטרה:** כל מאמץ (`RoleCategory`) ותפקיד (`RoleId`) מציגים את набור הקומפוננטות הנכון — ראשי, משני, ומפה.

| משימה | סטטוס | הערות |
|--------|--------|--------|
| מאמץ עליון — רשימות ב-`sidebarUiSpec.ts` | 🟡 | אג״ם: ת. קרב, סנכרון, תמ״כ; עורך/אש/…: 4 כפתורי תקיפה; מודיעין: בלי יומן |
| תפקיד — `ROLE_SIDEBAR_NAV` (חריגים) | 🟡 | למשל `planManagement` ל-`nihul-maarechet` |
| תחתית משותפת — עץ ציוות + תחקור + פקמ״ב + AI | ✅ | `SHARED_SIDEBAR_BOTTOM_NAV` + `SHARED_SIDEBAR_BOTTOM` |
| סיידבר **משני** לפי מאמץ | ⬜ | כיום רק **תחקור** (`TahkirParallelSideMenu`); האם מאמצים אחרים יקבלו משני? |
| כפתורי מפה לפי מאמץ | ⬜ | סדרן / שכבת תחקירים — מיקום ב-`layersToggleLeft` |
| מפרט מרוכז `roleUiSpec.ts` + מיזוג category/role | ⬜ | מתוכנן ב-[ROLE_DESIGN_SYSTEM.md](./docs/ROLE_DESIGN_SYSTEM.md) §7 |
| סנכרון מסמך מפרט ↔ קוד בכל שינוי | ⬜ | יומן שינויים §0 |

**קבצים:** `sidebarMenuRegistry.ts`, `sidebarUiSpec.ts`, `resolveSidebarUi.ts`, `shellLayout.ts`.

## 5. ריחוף מעל קומפוננטה — מי אחראי (אחריות פיתוח)

**מטרה:** בכל ריחוף (`title` / tooltip) — שם הקומפוננטה + **מי אחראי על הפיתוח**; הרחבה לכל המעטפת.

| קומפוננטה | אחריות (טקסט) | סטטוס מימוש |
|-----------|----------------|-------------|
| עץ ציוות | אחריות פיתוח שירות - אלביט · אחריות פיתוח ממשק - אגם | ✅ `sidebarMenuRegistry` |
| תחקור | אחריות פיתוח - מדור תחקור (בינה ולאסו) | ✅ |
| פקמ״ב | אחריות פיתוח - אג״ם | ✅ `SIDEBAR_COMPOSITE_DEV_RESPONSIBILITY` |
| AI | אחריות פיתוח - ענף 300 | ✅ |
| משימות, א.שטח, יומן, משמרת | — | ⬜ |
| ת. קרב, סנכרון מאמצים, תמ״כ, ניהול תוכנית | — | ⬜ |
| פס מסמכים (docStrip) | — | ⬜ |
| כותרת: Mission Plan, User, חיפוש | — | ⬜ |
| סדרן מרשמים / שכבת תחקירים (מפה) | — | ⬜ |
| מודול תת״ק (עתידי) | לקבוע בעת אפיון | ⬜ |

**איך מוסיפים (מימוש):**

1. שדה `devResponsibility` ב-`SidebarNavItemDef` — `src/types/sidebarUi.ts`
2. ערך ב-`src/data/rules/sidebarMenuRegistry.ts` (ניווט) או `SIDEBAR_COMPOSITE_DEV_RESPONSIBILITY` ב-`src/utils/sidebarHoverTitle.ts` (קומפוזיט)
3. בקומפוננטה: `title={sidebarHoverTitle(label, devResponsibility)}`
4. עדכון טבלה ב-[ROLE_DESIGN_SYSTEM.md](./docs/ROLE_DESIGN_SYSTEM.md) §3.1.1

**מתי ימומש (הצעה):**

| שלב | מה | מתי |
|-----|-----|------|
| א׳ | השלמת סייד-בר עליון + מרכז | עם סגירת §3 |
| ב׳ | כפתורי מפה + כותרת | עם ייצוב מעטפת תחקור/תת״ק |
| ג׳ | סדרן שכבות (שורות / תיקיות) | אופציונלי — tooltip עשיר יותר מ-`title` |
