# סדרן השכבות — עקרונות ופיצ'רים

## מבנה היררכי

```
תיקייה ראשית  (ניהו"ק / תכנון / מרשמי פלוגות)
  תת-תיקייה  (לחימה / מבצעים / אויב / …)
    שכבה
```

**תיקיות ראשיות:**
- **ניהו"ק** — שכבות המבצע הנוכחי
- **תכנון** — תוכניות לחימה עתידיות (מרשמי תכנון)
- **מרשמי פלוגות** — מסגרות כפופות

---

## מצבי סדרן: ניהו"ק ↔ תכנון

רק לחיצה על **הטוגל** בראש הסדרן מחליפה מצב — פתיחת תיקייה לא מחליפה.

| מצב | תיאור |
|-----|-------|
| ניהו"ק | מצב מבצעי — שכבות פעילות, מעקב כוחות |
| תכנון | שכבות תכנון עתידי; משפיע על אילו מרשמים פתוחים לעריכה |

---

## פילטר דרג צפייה

```
טכנו טקטי  →  מפקדה טקטית  →  מפקדה
```

דרג נמוך = פחות שכבות. דרג גבוה = כולל כל הדרגים שמתחתיו.

| תג | דרג |
|----|-----|
| טכנו טקטי (ירוק) | עד רמת הטנק |
| מפקדה טקטית (צהוב) | עד מפקד פלוגה |
| מפקדה (אדום) | הכל |

> פילטר הדרג **לא** נשמר בין סשנים — מאפס ל"הכל" בכניסה מחדש.

---

## ניהול נראות

- **עין חכמה** — מסתירה תיקייה ושומרת מצב; לחיצה חוזרת משחזרת בדיוק.
- **כבה/הדלק הכל** — ללא שמירת מצב.
- **מונה** `X/Y` — X בסדרן, Y סך הכל אפשרי.

---

## מצבי שיתוף שכבה

| תג | משמעות |
|----|--------|
| יח' (כחול) | יחידתי — רק היחידה שלך |
| עוצ' (סגול) | עוצבתי — כל החטיבה |
| מאגר (זהב) | משותף — כולם רואים |

---

## הרשאות עריכה

| קטגוריה | מה ניתן לעריכה |
|---------|----------------|
| אג"ם | כל מבצעים + איתורים, תיאום ושליטה, עזר הקרב |
| מודיעין | אויב, איסוף, שטח + עזר האויב, איתורים |
| אש | כל שכבות האש + איתורים |
| תקשוב | כל שכבות התקשוב |
| מנהלה | שכבת המנהלה בלבד |
| אורח | אין הרשאת עריכה |

כפתור ✏ בראש הסדרן פותח מצב עריכה. שכבות ללא הרשאה מוצגות נעולות.

---

## פיצ'רים נוספים

- **הוספת שכבות** — כפתור `+` בתת-תיקייה → בחירה ממפת השכבות.
- **שכבות טיוטה** — בתת-תיקייה ייחודית, דרג מפקדה בלבד; לא נשמרות בין סשנים.
- **↺ ברירת מחדל** — מחזיר תת-תיקייה לברירת המחדל של התפקיד הפעיל.
- **Drag & Drop** — גרירת שכבות לסידור מחדש בתוך תת-תיקייה.
